# ClonoDynamics methods documentation

This directory contains the extended scientific documentation for the current ClonoDynamics release.

## Documents

1. **[Primary analysis](01_primary_analysis.md)**
   Repertoire characterization, replicate-resolved state inference, transition construction, pseudo-longitudinal technical calibration, genuine forward dynamics, cross-replicate fluctuation dynamics, and temporal scaling (Steps 1–13).

2. **[Synthetic positive controls](02_positive_controls.md)**
   Support-conditioned semi-synthetic validation, oracle calibration, recovery through the production pipeline, verification, and current GitHub execution workflow.

3. **[Robustness and sensitivity controls](03_robustness_controls.md)**
   Interval-position/composition controls, fixed-threshold operational-domain sensitivity, and numerical observation-threshold robustness (Steps 14–16).

## Versioning principle

The files in `docs/methods/` are living software documentation and may be updated when repository paths, orchestration, or implementation details change. The exact methods accompanying a submitted or published manuscript should be frozen with the corresponding tagged software release.
